## 3. Truthful Scope & Readiness Breakdown

To maintain operational integrity, this report explicitly categorizes platform features across four operational readiness tiers:

### Tier 1: Implemented and Verified Locally
* **Accounts, Authentication & Session Security**: Email/password authentication, TOTP RFC 6238 Multi-Factor Authentication (AAL2), session invalidation.
* **Listing Lifecycle & Media Management**: Multi-step submission, automatic slug generation, image thumbnailing and derivatives via Sharp, moderation approval/rejection queue.
* **Search & Discovery**: Full-text and faceted search by category, condition, location, and price ranges; server-side pagination; zero-state handling.
* **Realtime Communication & Safety**: Bidirectional 1-on-1 messaging with client-side idempotency, abuse reporting queue, user blocking, and message evidence attachment.
* **Staff User Moderation (`/admin/users`, `/admin/users/[id]`)**: Search RPC, hardened suspension/reinstatement RPC (`admin_update_user_account_status`), immediate listing hiding cascade, suspended banner on `/account`.
* **Disaster Recovery**: Automated database and storage backup and verification against disposable targets.

### Tier 2: Implemented but Locally Verified Only
* **Transactional Email**: Verified via local Mailpit container (`http://127.0.0.1:54324`).
* **PostgreSQL & Storage Infrastructure**: Verified via local Supabase Docker stack (`127.0.0.1:54321` / `54322`).
* **Load Performance**: Verified via local synthetic load smoke tests (100 requests @ 25 concurrency). **This is NOT a production capacity certification.**

### Tier 3: External Prerequisites Required Before Public Pilot
1. **Production SMTP Provider**: Provision and verify production transactional email (Amazon SES, SendGrid, or Postmark) with authenticated DKIM/SPF domains.
2. **Statutory Grievance Officer**: In compliance with the Information Technology (Intermediary Guidelines and Digital Media Ethics Code) Rules of India, formally appoint and publish the Grievance Officer details.
3. **Production Domain & SSL/TLS**: Bind custom domain (`fairswap.in`) with automated certificate renewal.

### Tier 4: Explicitly Deferred to Phase 2 (Out of Scope for Milestone 1.6)
* Phase 2 Barter & Counter-Offer Negotiation Engine
* Digital Payments, Escrow, and Billing integrations
* Promoted / Sponsored Listings
* Geolocation radius / GPS search
* Native Mobile Applications (iOS / Android)
* SMS Integration (Phase 2 feature; NOT a pilot blocker)
