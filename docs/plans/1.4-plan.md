# Milestone 1.4 — Public Browsing, Discovery, and Favourites Implementation Plan

Revision: **r1** | Status: **READY FOR BUILD** | Date: 2026-09-13
Target Milestone: Milestone 1.4 (`docs/milestones/1.4-discovery.md`)
Baseline Commit: `0ca2083` (Phase1 branch)

## 1. Goal & Product Boundary

Deliver real public discovery and user favourites from approved local listings on local Supabase:
- Replace foundation mock previews with real approved listings.
- PostgreSQL full-text search with combined category, city/locality, price, and condition filters.
- Stable pagination and deterministic ordering with tie-breakers.
- Public screens: homepage with real data, search page with URL filters and keyboard-accessible controls, listing details keyed by stable ID/slug with photo gallery and minimal seller info, minimal seller public profiles with active listings, and authenticated favourites management.
- Visibility & security enforcement: public users and anonymous visitors can only access approved active listings (`is_listing_publicly_visible`); non-public listings (draft, rejected, paused, expired, removed, suspended sellers) are strictly withheld everywhere (database RLS, route handlers, HTML, metadata, and favourite joins).
- Obsolete slug redirection: old slugs redirect to current canonical slug ONLY after visibility is verified.
- SEO & metadata: accurate canonical URLs, social metadata, bounded sitemap, non-indexed development environment.
- Truthful draft help and policy pages with explicit draft labels and no false operational claims.
- Unavailable communication controls (chat/messaging) remain honest until Milestone 1.5.

### 1.1. In Scope

- **Migration 9 (`20260914000009_create_discovery_and_favourites.sql`)**:
  - Full-text search `search_vector` generated column on `listings` using PostgreSQL `to_tsvector('english', ...)`. GIN index on `search_vector`.
  - Composite indexes for filtering and stable pagination: `(status, created_at DESC, id DESC)`, `(status, price_paise ASC, id ASC)`, `(status, price_paise DESC, id DESC)`, `(category_id, status, created_at DESC, id DESC)`, `(city_id, status, created_at DESC, id DESC)`, `(city_id, locality_id, status, created_at DESC, id DESC)`.
  - `listing_slug_history` table to track prior slugs for SEO 301 redirects (`listing_id`, `slug`, `created_at`). Trigger on `listings.slug` update to record history.
  - `public.favourites` table (`user_id`, `listing_id`, `created_at`, PK `(user_id, listing_id)`) with RLS and grants.
  - Column-level `SELECT` grants on `public.listings` and `public.listing_media` for `anon` and `authenticated`.
  - Updated RLS policies on `public.listings` and `public.listing_media` granting public read for items matching `is_listing_publicly_visible(id)`.
  - RPC `public.search_public_listings(...)` supporting keyword full-text query, category, city, locality, price range, condition, sort order, and bounded pagination with total match count.
- **Photo & Media Delivery**:
  - Update `GET /api/listings/[id]/media/[mediaId]/[size]`:
    - Derivatives (`thumb`, `medium`, `large`): publicly accessible if listing is publicly visible (`is_listing_publicly_visible`). If not publicly visible, access restricted to owner or staff.
    - `original`: strictly restricted to owner or staff with moderator/admin role.
    - Cache headers: `public, max-age=3600, s-maxage=3600` for public derivatives; `private, no-store` for authenticated private access.
  - Update `next.config.ts`: configure `images.remotePatterns` restricted to local Supabase Storage host and derivatives path.
- **Public Screens & Routes**:
  - Homepage (`/`): Real categories, search bar with city filter, latest active listings, responsive cards.
  - Search / Browse (`/search`): Full combined filter bar (keyword, category, city, locality, condition, price range, sort), keyboard accessibility, zero-result empty state, bounded pagination.
  - Listing Detail (`/listings/[slugOrId]`): Keyed by slug or ID. Resolves slug history with visibility verification before 301 redirect. Photo gallery with keyboard navigation, price, condition, category attributes, location disclaimer, minimal seller card, honest contact button with M1.5 preview notice, favourite toggle.
  - Seller Profile (`/seller/[id]`): Minimal public profile (display name, avatar, bio, city, state, member since), seller's active listings grid.
  - Favourites (`/account/favourites`): Authenticated user's saved listings. Graceful handling of no-longer-available items without leaking private titles/images.
- **Draft Help, Safety & Policy Pages**:
  - `/help`: Truthful FAQ and guidance.
  - `/safety`: Public safety precautions for local transactions.
  - `/terms`: Draft Terms of Service with development preview banner.
  - `/privacy`: Draft Privacy Policy with development preview banner.
  - `/contact`: Operational status disclosure (no live support queues until M1.5/M1.6).
- **SEO & Metadata**:
  - Dynamic OpenGraph and canonical metadata on listings and public pages.
  - `src/app/robots.ts`: Disallow crawling in non-production / development environments.
  - `src/app/sitemap.ts`: Bounded sitemap of public pages, categories, cities, and active listings.
- **Testing & Verification**:
  - Database RLS and search RPC tests in Vitest.
  - Visibility leakage tests (drafts/rejected/paused/expired items cannot be found in search, direct listing route, media route, slug redirect, or favourite joins).
  - Playwright E2E browser tests: searching, filtering, keyboard navigation, viewing listing details, favouriting with authenticated session, viewing seller profile.

### 1.2. Explicitly Excluded

- Real-time buyer-seller chat / messaging (Milestone 1.5).
- Abuse reporting, user blocking, and support dispute cases (Milestone 1.5).
- External search engine clusters (e.g. MeiliSearch, Elasticsearch) or external recommendations.
- Saved-search email alerts or push notifications.
- Distance / geolocation radius calculation (only city/locality matching).
- Payment gateways, escrow, shipping, or purchase checkouts.
