## Gate and outcome

Reference contract only; requires accepted 1.2 and a separately reviewed/authorized 1.3 plan. Deliver the real seller-to-moderator workflow on local Supabase. Public discovery belongs to 1.4; no public launch yet.

## Plan first

Read implemented accounts/roles/schema and relevant master sections. Design incremental category/location/listing/media/revision tables, typed attributes, state-transition matrix, image processing/delivery, and direct-API policies. Specify private originals/derivatives, resource limits, cleanup, and cache/signed-URL limitations. Record actual dependencies and SQL/function privilege changes before approval.

## Build batches

A. Category/location administration: create configurable categories, typed attribute definitions/values, city/locality references, safe validation and staff management screens. Seed a documented sample pilot location and selected permitted categories only. Prevent edits to definitions from silently invalidating published advertisements.

B. Seller listings: draft/preview/submit/edit, structured condition/price fields with integer paise, approximate location, owner-managed listing dashboard, bounded validation and ownership constraints. Allow incomplete drafts but not incomplete submissions.

C. Photos: real Supabase Storage with owner/path policies; actual-content validation, safe decoding/resource bounds, metadata removal/re-encoding, thumbnails/derivatives, cover/order, progress/retry, and orphan tracking. Private originals never become public. Approvals require successful processing. No arbitrary URL fetch or unsafe file format. Introduce only narrowly scoped image dependencies.

D. Moderation and lifecycle: approved staff see pending listings and revisions, approve/reject/remove with reasons, and audit actions. Enforce allowed state changes in the database, not only UI. Material edits become pending review; seller restore/renew cannot bypass removal or restrictions. Reserved is informational. Expiry and suspension affect access even when a job has not run.

E. Maintenance: add only currently needed authenticated idempotent media/expiry jobs with limits and failure tracking. Preserve justified records instead of blind cascading deletes. Keep private draft/detail access separate from the future public pages.

Develop a reusable public-read authorization function/query for future discovery only where needed to verify real visibility policies. Do not build a fake catalogue or search screen early. Seed approximately 30 clearly synthetic local advertisements with licensed/local image fixtures and provenance; scripts must refuse production targets.

## Required tests

Verify CRUD/validation and real local storage/database authorization: other seller edits denied; self-approval/owner/status manipulation denied; material changes re-reviewed; resume/renew/remove/expiry behavior; suspended seller visibility; invalid attributes after category change; price bounds; cross-owner uploads/overwrites/deletes; oversized/malformed/pixel-bomb image rejection; original/draft access denied; signed-URL/cache limitations; orphan cleanup idempotency; moderation audit.

Browser-test actual seller submission with photos, moderator approval/rejection, and seller status updates. Test unauthorized direct API and storage paths, not only page redirects. If a real image pipeline cannot run, mark it blocked rather than silently storing unsafe originals publicly.

## Exclusions

No search/favourites, message system, support-case UI, subscriptions, shipping, or purchase flows. No public-star ratings or fake seller guarantees.

## Acceptance

- Typed categories, locations, real forms, drafts and submissions persist correctly.
- Valid photos process safely; ownership/storage boundaries hold.
- Staff reviews and state transitions work and are audited.
- Hidden, expired, suspended, or unreviewed content is not public through database/media routes.
- Actual local migrations, RLS/storage tests, browser flows and prior regressions pass.
- Schema/types, media-delivery design, operational limits and seed provenance documented.
- Changes/evidence reported for human review; no automatic advance to 1.4.
