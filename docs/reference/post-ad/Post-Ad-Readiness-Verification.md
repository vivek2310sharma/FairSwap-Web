## Freshness limits retained

These are multiple reads, not an atomic packet. An unchanged ending identity remains not_verified for atomic freshness; mismatches/missing ending reads require refresh and retain the captured identity. Existing contract analysis records reviewed moderation comparing expected revision AND status under a listing lock (PT409 on conflict), material active/reserved/paused edits triggering re-review, and rejected content edits returning to draft. Ordinary pending-review content edits remain denied. Pending media changes are allowed but the current re-review/reorder revision coverage only addresses active/reserved/paused. Draft-only family contexts/financial changes also lack complete review-identity coverage. This batch changes none of those triggers, callers or operations. Future approval must lock/compare the reviewed identity and never silently substitute a refreshed revision; context/photo changes need complete revision coverage first.
